## 🚀 第一次使用

### 打开视频
直接拖拽视频文件到 mpv 窗口，或双击视频文件用 mpv 打开。

### 基本操作
| 操作 | 按键 |
|------|------|
| 播放/暂停 | `空格` |
| 快进/快退 | `→` / `←` |
| 调节音量 | `↑` / `↓` |
| 全屏 | `F` |

## 🎯 8 个高频场景

### 场景 1：追番自动连播

**问题**：每次都要手动点开下一集？

**解决**：
1. 打开任意一集视频
2. 自动加载同目录下所有视频到播放列表
3. 看完一集自动播放下一集

**调整顺序**：按 `Shift + Enter` 打开播放列表，拖动调整

**详细配置**：[README.md#autoloadlua](README.md#autoloadlua)

---

### 场景 2：跳过片头片尾

**问题**：每集都要看同样的 OP/ED？

**解决**：
1. 首次播放时自动检测片头片尾位置
2. 到达跳过点时自动跳转（OSD 显示提示）
3. 同目录后续集数自动应用跳过位置

**手动标记**（自动检测失败时）：
1. 播放到片头开始位置，按 `Shift + M`
2. 播放到片头结束位置，再按 `Shift + M`
3. 保存到历史记录，后续集数自动应用

**配置调整**：[README.md#chapterskiplua](README.md#chapterskiplua)

---

### 场景 3：下载中文字幕

**问题**：外语电影没有中文字幕？

**解决**：
1. 按 `S` 打开字幕搜索
2. 自动根据视频名搜索，显示结果列表
3. 用 `↑` `↓` 选择，按 `Enter` 下载并自动加载

**首次使用**：
1. 访问 https://assrt.net 注册账号
2. 进入个人中心获取 API Token
3. 打开 `script-opts/sub_assrt.conf`，填入 `api_token=你的 token`

**手动搜索**：按 `Ctrl + S`，输入关键词（如 "剧名 S01E02"）

**详细配置**：[README.md#sub-assrtlua](README.md#sub-assrtlua)

---

### 场景 4：找回上次观看位置

**问题**：昨天看到一半的电影，今天找不到上次的位置？

**解决**：
1. 按 `H` 打开历史记录
2. 用 `↑` `↓` 选择视频
3. 按 `Enter` 直接跳转到上次观看位置继续

**搜索历史**：在列表中直接输入关键词

**删除记录**：选择后按 `Del`

**详细配置**：[README.md#simplehistorylua](README.md#simplehistorylua)

---

### 场景 5：标记视频重点

**问题**：教程视频太长，想标记重点位置方便回顾？

**解决**：
1. 播放到重要位置，按 `Ctrl + B` 保存书签
2. 输入书签名称（可选），如 "第三章：安装配置"
3. 需要时按 `B` 打开书签列表，选择后按 `Enter` 跳转

**快速槽位**（标记 9 个以内关键点）：
- 播放到位置，按 `Ctrl + 1` 保存到槽位 1
- 需要时按 `Ctrl + 1` 直接跳转

**分组管理**：保存时选择分组（如 "教程/Python/第 3 章"）

**详细配置**：[README.md#simplebookmarklua](README.md#simplebookmarklua)

---

### 场景 6：快速跳过冗长片段

**问题**：想跳过冗长片段，但怕错过关键内容？

**解决**：
- **轻按 `→`**：快进 5 秒
- **长按 `→`**：加速播放（最高 3 倍速）
- **字幕出现时**：自动限速到 1.5 倍，不错过字幕

**调整速度**：[README.md#evafastlua](README.md#evafastlua)

---

### 场景 7：整理播放列表

**问题**：播放列表文件太多，想找特定视频？

**解决**：
1. 按 `Shift + Enter` 打开播放列表
2. **搜索**：直接输入关键词
3. **排序**：按 `S` 选择排序方式（名称/日期/大小）
4. **移除**：选择文件后按 `Del`

**加载文件夹**：按 `L` 加载文件，`Ctrl + D` 加载整个目录

**保存列表**：按 `P` 保存，下次按 `L` 加载

**详细配置**：[README.md#playlistmanagerlua](README.md#playlistmanagerlua)

---

### 场景 8：使用现代化界面

**问题**：不喜欢默认的简陋界面？

**解决**：uosc 提供现代化 UI

- **鼠标悬停**：显示进度条和控制按钮
- **拖动进度条**：显示缩略图预览
- **右键点击**：打开上下文菜单
- **滚轮**：调节音量或快进/退

**界面元素**：
- 底部进度条（带缩略图预览）
- 顶部标题栏（显示视频信息）
- 右侧音量控制
- 底部控制按钮（播放/暂停、字幕、音轨等）

**调整样式**：[README.md#uosc](README.md#uosc)

## ❓ 常见问题

**Q: 为什么不自动加载同目录的视频？**  
A: 检查 `script-opts/autoload.conf` 中 `disabled=no` 和 `videos=yes`。

**Q: 字幕搜索失败，显示 API 错误？**  
A: 确认已注册 https://assrt.net 并获取 API Token，在 `sub_assrt.conf` 填入正确的 `api_token`。

**Q: 历史记录在哪里保存？**  
A: `portable_config/files/mpvHistory.log`，可直接编辑删除特定记录。

**Q: 书签在哪里保存？**  
A: `portable_config/files/mpvBookmark.log`，JSON 格式可直接编辑备份。

**Q: 界面显示乱码？**  
A: 确保系统安装了中文字体，在 `uosc.conf` 设置 `font=Noto Sans CJK SC`。

**更多问题**：[README.md#-常见问题](README.md#-常见问题)
