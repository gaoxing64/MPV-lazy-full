## 第一次使用

**打开视频**：拖拽文件到 mpv 窗口，或双击视频文件。

**基本操作**：
| 操作 | 按键 |
|------|------|
| 播放/暂停 | `空格` |
| 快进/快退 | `→` / `←` |
| 音量 | `↑` / `↓` |
| 全屏 | `F` |

## 8 个常用场景

### 1. 追番自动连播

**问题**：每次都要手动点开下一集？

**解决**：
1. 打开任意一集视频
2. 自动加载同目录下所有视频到播放列表
3. 看完一集自动播放下一集

**调整顺序**：按 `Shift + Enter` 打开播放列表拖动

**配置**：[README.md#autoloadlua](README.md#autoloadlua)

---

### 2. 跳过片头片尾

**问题**：每集都要看同样的 OP/ED？

**解决**：
1. 首次播放自动检测片头片尾位置
2. 到达跳过点自动跳转（OSD 提示）
3. 同目录后续集数自动应用

**手动标记**（检测失败时）：
1. 片头开始按 `Shift + M`
2. 片头结束再按 `Shift + M`
3. 自动保存，后续集数应用

**配置**：[README.md#chapterskiplua](README.md#chapterskiplua)

---

### 3. 下载中文字幕

**问题**：外语电影没有中文字幕？

**解决**：
1. 按 `S` 打开字幕搜索
2. 自动根据视频名搜索
3. 选择后按 `Enter` 下载并加载

**首次使用**：
1. 访问 https://assrt.net 注册
2. 获取 API Token
3. 编辑 `script-opts/sub_assrt.conf` 填入 `api_token`

**手动搜索**：按 `Ctrl + S` 输入关键词

**配置**：[README.md#sub-assrtlua](README.md#sub-assrtlua)

---

### 4. 找回上次观看位置

**问题**：昨天看到一半的电影找不到位置？

**解决**：
1. 按 `H` 打开历史记录
2. 选择视频按 `Enter`
3. 跳转到上次位置继续

**搜索**：列表中直接输入关键词

**删除**：选择后按 `Del`

**配置**：[README.md#simplehistorylua](README.md#simplehistorylua)

---

### 5. 标记视频重点

**问题**：教程太长想标记重点？

**解决**：
1. 播放到重点按 `Ctrl + B`
2. 输入名称（可选）
3. 需要时按 `B` 打开列表跳转

**快速槽位**（9 个关键点）：
- 按 `Ctrl + 1` 保存到槽位 1
- 按 `Ctrl + 1` 直接跳转

**配置**：[README.md#simplebookmarklua](README.md#simplebookmarklua)

---

### 6. 快速跳过冗长片段

**问题**：想跳过片段但怕错过内容？

**解决**：
- 轻按 `→`：快进 5 秒
- 长按 `→`：加速播放（最高 3 倍）
- 字幕出现：自动限速 1.5 倍

**配置**：[README.md#evafastlua](README.md#evafastlua)

---

### 7. 整理播放列表

**问题**：播放列表文件太多不好找？

**解决**：
1. 按 `Shift + Enter` 打开列表
2. 输入关键词搜索
3. 按 `S` 排序
4. 按 `Del` 移除

**加载文件夹**：`L` 加载文件，`Ctrl + D` 加载目录

**保存列表**：按 `P` 保存，下次按 `L` 加载

**配置**：[README.md#playlistmanagerlua](README.md#playlistmanagerlua)

---

### 8. 使用现代化界面

**问题**：不喜欢默认简陋界面？

**解决**：uosc 提供现代化 UI

- 鼠标悬停：显示进度条和按钮
- 拖动进度条：显示缩略图
- 右键：上下文菜单
- 滚轮：音量或快进

**界面**：进度条、标题栏、音量控制、控制按钮

**配置**：[README.md#uosc](README.md#uosc)

## 常见问题

**Q: 为什么不自动加载同目录视频？**  
A: 检查 `autoload.conf` 中 `disabled=no` 和 `videos=yes`。

**Q: 字幕搜索失败？**  
A: 在 `sub_assrt.conf` 填入 assrt.net 的 API Token。

**Q: 历史记录在哪？**  
A: `portable_config/files/mpvHistory.log`，可直接编辑。

**Q: 书签在哪？**  
A: `portable_config/files/mpvBookmark.log`，JSON 格式可编辑。

**Q: 界面乱码？**  
A: `uosc.conf` 设置 `font=Noto Sans CJK SC`。
