## 📌 5 分钟上手

### 第一步：打开视频
直接拖拽视频文件到 mpv 窗口，或双击视频文件用 mpv 打开。

### 第二步：基本操作
| 操作 | 按键 |
|------|------|
| 播放/暂停 | `空格` 或 `P` |
| 快进/快退 | `→` / `←`（**长按可加速播放**，字幕出现时自动减速） |
| 调节音量 | `↑` / `↓` |
| 全屏 | `F` 或 `Enter` |
| 截图 | `S` |

### 第三步：打开菜单
- **播放列表**：`Shift + Enter` - 查看和管理当前播放列表
- **历史记录**：`H` - 找回之前看过的视频
- **书签**：`B` - 查看已保存的书签
- **字幕下载**：`S` - 在线搜索并下载中文字幕

## 🎯 高频使用场景

### 场景 1：追番/追剧 - 自动连播
**问题**：每次都要手动点开下一集？

**解决**：
1. 打开任意一集视频
2. 脚本会**自动加载同目录下的所有视频**到播放列表
3. 看完一集自动播放下一集

**进阶**：
- 按 `Shift + Enter` 打开播放列表，可调整顺序、移除不需要的文件
- 按 `R` 随机打乱播放顺序

---

### 场景 2：跳过片头片尾 - 省时间
**问题**：每集都要看同样的 OP/ED？

**解决**：
1. 首次遇到片头时，脚本会**自动检测并跳过**（OSD 显示"跳过片头"）
2. 脚本会记住跳过位置，**同目录的后续集数自动应用**

**手动标记**（如果自动检测失败）：
1. 按 `Shift + M` 开始标记
2. 在片头结束位置再按 `Shift + M`
3. 保存到历史记录，下次自动跳过

**配置**：`script-opts/chapterskip.conf`
```ini
mode=auto          # 自动跳过（改为 manual 需要确认）
skip=opening;ending  # 跳过片头片尾
```

---

### 场景 3：下载中文字幕 - 无字幕视频救星
**问题**：下载的外语电影没有中文字幕？

**解决**：
1. 按 `S` 打开字幕搜索
2. 自动根据视频名搜索，显示结果列表
3. 用 `↑` `↓` 选择，按 `Enter` 下载
4. 下载完成后**自动加载字幕**

**首次使用**：
1. 访问 https://assrt.net 注册账号
2. 进入个人中心获取 API Token
3. 打开 `script-opts/sub_assrt.conf`，填入：
```ini
api_token=你的 token
```

**手动搜索**：按 `Ctrl + S`，输入关键词（如 "剧名 S01E02"）

---

### 场景 4：找回上次观看的视频 - 历史记录
**问题**：昨天看到一半的电影，今天找不到了？

**解决**：
1. 按 `H` 打开历史记录
2. 用 `↑` `↓` 选择视频
3. 按 `Enter` 直接**跳转到上次观看的位置**继续

**技巧**：
- 在列表中按 `Ctrl + F` 搜索关键词
- 按 `DEL` 删除不需要的历史记录
- 按 `Esc` 关闭列表

**隐身模式**（不记录历史）：
- 按配置中的快捷键切换隐身模式
- 适合观看隐私内容时使用

---

### 场景 5：标记精彩片段 - 书签
**问题**：教程视频太长，想标记重点位置方便回顾？

**解决**：
1. 播放到重要位置，按 `Ctrl + B` 保存书签
2. 输入书签名称（可选），如 "第三章：安装配置"
3. 按 `B` 打开书签列表，选择后按 `Enter` 快速跳转

**快速槽位**（标记 9 个以内的关键点）：
- `Ctrl + 1` 到 `Ctrl + 9`：快速保存/跳转
- 适合标记视频教程的章节

**分组管理**：
- 保存时选择分组（如 "教程/Python/第 3 章"）
- 按 `Ctrl + 1~5` 快速切换到预设分组（电视剧/电影/动画等）

---

### 场景 6：快速定位 - 智能快进
**问题**：想跳过冗长片段，但怕错过关键内容？

**解决**：
- **轻按 `→`**：快进 5 秒
- **长按 `→`**：加速播放（最高 3 倍速）
- **字幕出现时**：自动限速到 1.5 倍，不错过字幕

**配置**：`script-opts/evafast.conf`
```ini
seek_distance=5      # 每次跳转 5 秒
speed_cap=3          # 最高 3 倍速
subs_speed_cap=1.5   # 有字幕时最高 1.5 倍
```

---

### 场景 7：整理播放列表 - 批量管理
**问题**：播放列表文件太多，想找特定视频？

**解决**：
1. 按 `Shift + Enter` 打开播放列表
2. **搜索**：直接输入关键词
3. **排序**：按 `S` 选择排序方式（名称/日期/大小）
4. **移除**：选择文件后按 `Del`

**加载文件夹**：
- 按 `L` 加载文件
- 按 `Ctrl + D` 加载整个目录

**保存播放列表**：
- 按 `P` 保存当前列表
- 下次按 `L` 加载继续观看

---

### 场景 8：现代化界面 - 鼠标操作
**问题**：不喜欢默认的简陋界面？

**解决**：uosc 提供现代化 UI
- **鼠标悬停**：显示进度条和控制按钮
- **拖动进度条**：显示缩略图预览
- **右键点击**：打开上下文菜单
- **滚轮**：调节音量或快进/退

**界面元素**：
- 底部进度条（带缓冲指示）
- 顶部标题栏（显示视频信息）
- 右侧音量控制
- 底部控制按钮（播放/暂停、字幕、音轨等）

**配置**：`script-opts/uosc.conf`
```ini
timeline_size=30     # 进度条大小
controls_size=32     # 按钮大小
font=Noto Sans CJK SC  # 中文字体
```

## 🔧 常用配置速查

### 修改配置通用步骤
1. 用文本编辑器打开对应的 `.conf` 文件
2. 修改参数值
3. 保存后**立即生效**（部分需要重新加载视频）

### 核心配置文件

| 文件 | 功能 | 推荐修改 |
|------|------|----------|
| `uosc.conf` | 界面样式 | 字体、颜色、进度条大小 |
| `evafast.conf` | 快进功能 | 跳转距离、最高速度 |
| `autoload.conf` | 自动加载 | 文件类型、子目录模式 |
| `chapterskip.conf` | 跳过片头片尾 | 跳过模式、时间窗口 |
| `sub_assrt.conf` | 字幕下载 | API Token |
| `simplehistory.conf` | 历史记录 | 最大数量、隐身模式 |
| `simplebookmark.conf` | 书签 | 分组设置、快速槽位 |
| `playlistmanager.conf` | 播放列表 | 显示行数、排序方式 |

## ❓ 常见问题

### Q: 为什么不自动加载同目录的视频？
**A**: 检查 `script-opts/autoload.conf`：
```ini
disabled=no        # 确保未禁用
videos=yes         # 确保启用视频加载
same_type=yes      # 只加载同类型文件
```

### Q: 字幕搜索失败，显示 API 错误？
**A**: 
1. 确认已注册 https://assrt.net 并获取 API Token
2. 在 `script-opts/sub_assrt.conf` 填入正确的 `api_token`
3. 检查网络是否可以访问射手网

### Q: 历史记录在哪里保存？
**A**: 默认保存在 `portable_config/files/mpvHistory.log`
- 可直接编辑删除特定记录
- 按 `Ctrl + H` 清空所有历史

### Q: 书签在哪里保存？
**A**: 默认保存在 `portable_config/files/mpvBookmark.log`
- JSON 格式，可直接编辑备份
- 支持导出分享

### Q: 如何禁用某个功能？
**A**: 大部分脚本支持在配置文件中设置 `disabled=yes` 或 `auto_run=no`
- 查看对应 `.conf` 文件顶部的注释
- 不要删除文件，只需注释或修改参数

### Q: 界面显示乱码？
**A**: 
1. 确保系统安装了中文字体（如 Noto Sans CJK SC）
2. 在 `uosc.conf` 中设置正确的字体：
```ini
font=Noto Sans CJK SC
```

├── scripts/              # 脚本文件（不要修改）
